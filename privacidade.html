Privacidade e acesso ao YouTube

Política de Privacidade

Esta política descreve o uso das permissões do YouTube pelo aplicativo privado Instinto Curioso. Última atualização: 13 de novembro de 2026.

Nesta páginaResponsável e finalidadePermissões solicitadasDados e usoArmazenamento e retençãoRevogaçãoEste siteContato

1. Responsável e finalidade

Instinto Curioso é uma ferramenta privada usada pelo responsável pelo canal Instinto Curioso no YouTube para conferir a conta autorizada e automatizar o envio de vídeos sobre animais, natureza e ciência. O aplicativo não oferece acesso a terceiros por este site.

2. Permissões solicitadas

youtube.readonly

Permite consultar a conta do YouTube autorizada. No fluxo de autorização, o aplicativo usa channels.list(mine=true) para conferir o identificador do canal antes de salvar o token.

youtube.upload

Permite enviar vídeos ao canal autorizado por meio da API do YouTube quando a automação é executada. A página pública não envia vídeos.

Essas permissões são concedidas pelo titular da Conta Google na tela de consentimento do Google. O aplicativo não solicita a senha da Conta Google.

3. Dados acessados e uso

A validação consulta o identificador e informações básicas do canal retornadas pela API do YouTube para confirmar que a conta autorizada administra o canal pretendido. Para um envio, a automação transmite ao YouTube o arquivo de vídeo e os dados necessários à publicação configurada. Não usamos as permissões para ler canais de visitantes deste site.

O token OAuth é trocado com os serviços do Google para autorizar essas operações. Ele não é publicado no repositório do site nem enviado aos visitantes.

4. Armazenamento, proteção e retenção

O arquivo de credenciais OAuth foi salvo no computador usado para a autorização e transferido por SSH para uma pasta privada de configuração na VPS que executa a automação, fora do repositório público. Na configuração verificada, a pasta da VPS tem permissão 700 e o token tem permissão 600. O aplicativo pode atualizar o arquivo do token quando renova o acesso.

Não foi configurado um prazo de exclusão automática para esse arquivo. Ele permanece enquanto for necessário para a automação, até ser substituído, removido ou invalidado. O Google também pode expirar ou revogar o token segundo suas regras. A revogação impede novas chamadas autorizadas, mas a cópia do arquivo deve ser removida separadamente dos locais onde foi guardada.

5. Como revogar o acesso

O titular pode revogar o acesso do Instinto Curioso nas conexões da Conta Google. Também pode solicitar ao responsável pela automação que remova as cópias do token do computador de autorização e da VPS. Após a revogação, uma nova autorização será necessária para voltar a usar o aplicativo.

6. Este site público

Estas páginas são estáticas e hospedadas pelo GitHub Pages. Não têm formulário de login, cookies próprios nem código de análise adicionado pelo aplicativo. O GitHub pode tratar dados técnicos de acesso conforme sua declaração de privacidade. Visitar este site não concede acesso ao seu YouTube.

7. Contato

Para dúvidas gerais, abra uma solicitação no repositório deste site. Não inclua tokens, senhas ou informações pessoais em uma solicitação pública. Para um pedido privado, use o endereço de suporte apresentado na tela de consentimento OAuth do aplicativo.
